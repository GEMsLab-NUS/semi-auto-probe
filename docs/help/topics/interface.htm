状态与任务占用

页面底部或卡片内的状态文本是首要诊断信息。自动工作流运行时，应用会锁住可能冲突的运动、配置或原始通信操作。看到 “Motion busy”“workflow is running” 或 “locked” 时，先等待当前步骤终止，或使用该工作流的 Stop；紧急情况使用顶栏急停。

  • 绿色/青色 通常表示已连接、完成或满足条件。
  • 黄色 通常表示离线、等待、部分有效或需要检查。
  • 红色 表示失败、被阻止或危险动作。

窗口与 F1

按 F1 会读取当前页面并打开对应 CHM context ID。焦点位于输入框时也可使用 F1，不会把按键交给运动控制。Measurement Workflow 等带有独立帮助上下文的子窗口会打开更具体的主题。
