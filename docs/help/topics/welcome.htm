软件用途

Semi Auto Probe 是三轴 RS-232 运动控制与 USB 显微视觉工作站。它把手动定位、自动对焦、焦平面建模、版图坐标映射、图像拼接、矩阵采集、探针测试、Wire-bond Mapping、仪器工作流和受控 AI 助手放在同一桌面应用中。

需要做什么从哪里开始
首次连接控制器和相机快速开始，然后查看 Communication
手动移动与观察样品MainView
建立表面焦平面AutoFocus 与 FocusMap
把 GDS 坐标绑定到载台LayoutMap / LayoutBond
批量图像或测量ImgMatrix、AutoTest 与 Measurement Workflow v2
让 Agent 解释或执行受控步骤AI Agent
查看会话结果文件、会话与导出 或 Web Dashboard

手册范围

本手册以应用版本 0.1.0、代码与界面状态 2026-09-07 为基线。页面名称以界面可见标签为准；历史代码中的 Main、LayoutBond、Communication、Config 分别对应 MainView、LayoutMap、SerialIO、Settings。

所有设备参数、输出目录和状态说明均来自当前实现。设备型号、接线和实验限值仍以实验室 SOP、仪器铭牌和样品工艺要求为准。

帮助窗口的使用方法

  • 目录：按实际操作顺序浏览主题。
  • 索引：按页面名、仪器名、文件名或术语定位说明；可使用中文或英文 UI 词查找关键词。
  • F1：从任一主页面打开相应主题；工作流编辑器等子窗口会使用自己的帮助上下文。
