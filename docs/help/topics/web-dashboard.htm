SEMI AUTO PROBE · OFFICIAL HELP

Web Dashboard

以只读方式浏览 AutoTest/Mapping 会话、文件树、JSON 摘要和文本结果。

启动

$env:SEMI_AUTO_PROBE_WEB_TOKEN = "use-a-strong-token"
$env:SEMI_AUTO_PROBE_AUTOTEST_SESSION_DIR = "D:\data\autotest_session"
uv run semi-auto-probe-web

默认地址为 http://127.0.0.1:8000。可用 SEMI_AUTO_PROBE_WEB_HOST 和 SEMI_AUTO_PROBE_WEB_PORT 修改监听地址/端口。

认证不是默认强制。只有设置 SEMI_AUTO_PROBE_WEB_TOKEN 后，API 才检查 token。向 LAN 或公网监听前必须设置强 token、限制网络访问，并确认 session 中没有敏感数据。

认证与浏览器

API 接受 X-Access-Token header 或 ?token= query。网页收到 URL token 后会保存到 browser localStorage 并从地址栏移除。401 时核对服务进程实际环境、浏览器保存值与 header。

当前功能

  • 系统 status 与 connections 摘要。
  • 列出 session、聚合 latest、选择单个 session。
  • 显示安全限制在 session root 内的文件树。
  • 预览 JSON 摘要、CSV/TXT/LOG 文本；内联查看或下载文件。

明确不提供的功能

当前 Web 不发布 camera，不提供 serial port/position，也没有 motion、probe 或 E-stop 控制。兼容端点会返回 disabled 或 HTTP 410。所有硬件控制仍在本机桌面应用和物理安全装置中完成。

环境变量

变量用途
SEMI_AUTO_PROBE_AUTOTEST_SESSION_DIRsession root；默认是启动目录下 autotest_session。
SEMI_AUTO_PROBE_WEB_TOKEN启用访问认证；也可作为桌面 Admin token fallback。
SEMI_AUTO_PROBE_WEB_HOST / ..._PORT监听 host 与端口。
SEMI_AUTO_PROBE_WEB_CORS_ORIGINS逗号分隔的允许 origin。
SEMI_AUTO_PROBE_HOMEPAGE_DIR自定义首页静态资源。
SEMI_AUTO_PROBE_WEB_PID_FILEPID 文件；默认 .runtime/semi-auto-probe-web.pid。

Tray 部署

Windows tray 脚本可提供 Open Dashboard、AutoTest Sessions、Restart Web Service、Stop Running、Update Token 与 Check Connections；运行日志位于 .runtime/restart_web.log 和 .runtime/web_tray.log。
