SerialIO：控制器通信

发送协议帧、读取原始响应并诊断本地或远程串口。

维护功能。SerialIO 可绕过高层动作语义。仅发送已确认的控制器命令；自动测量或 Mapping 运行时，应用会锁住 raw command。

顶栏连接

  1. 选择 Local 使用本机 COM 端口，或选择 Remote 使用已配置的 SSH 串口桥。
  2. 单击 Refresh 更新端口；选择目标端口后单击 Connect。
  3. 单击 Test 执行默认通信测试。控制器、RS-232 接线、端口占用和协议参数均正确时，状态应成功，默认 RX 前缀为 A3 AA。

Manual Command

控件说明
Hex / TextHex 按字节输入十六进制；Text 发送文本负载。不要把含空格的文本误当成 Hex。
Read bytes发送后尝试读取的字节数，必须为 0 或正整数。
Load Test载入默认通信测试帧和说明。
Send发送输入内容；输入框中 Ctrl+Enter 也会发送。
Clear清除 TX/RX 与通信历史显示，不改变控制器状态。

诊断读法

LAST TX 是最近发送帧，LAST RX 是最近响应，HEX COMMUNICATION HISTORY 按时间保留交互。诊断时记录命令、完整响应、端口模式和顶栏状态。

现象检查
没有端口Windows 设备管理器、USB/串口驱动、线缆，再按 Refresh。
Connect 失败端口是否被其他程序占用；控制器电源与 RS-232；默认 115200、8 data bits、no parity、1 stop bit。
Test 无响应或前缀错误核对协议、read bytes、发送模式和控制器固件；查看完整历史，不要只依据状态摘要。
Remote 不可用SSH key、远端 host、串口桥状态及远端设备占用。
