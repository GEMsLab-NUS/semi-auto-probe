Keithley 2450 与 HP 6614C

节点关键配置与结果
Keithley IVvoltage/current sweep、single/往返 scan、start/stop/step、voltage/current limit、range、NPLC、terminal、output-off、statistics 与 resistance。
2450 Fixed-bias Current固定 Bias，按 sample count 采样；可在 Mapping 点间 hold。可选择 TEMT6000 optical model、wavelength、power correction 与 dark offset。
WobbTest在 Keithley bias 下扫描 Z，并可继续 XY 优化接触。固定 Z Wire-bond Mapping 中禁止。当前实际结果含 best_current_a；声明的 contact_resistance_ohm 尚未计算。
6614C TransferHP 6614C 扫 Vg，Keithley 保持 Vd 并测 Id；设置 HP/Keithley resource、bias list、compliance、NPLC 与 settle。
6614C OutputKeithley 扫 Vd，HP 6614C 应用每个 Vg；输出 curve、JSON/CSV 与特征。
6614C Gate Bias LoopScratch 风格容器：把一张 Keithley IV 卡拖入容器；HP 6614C 依次应用 Vg 列表，每个栅压完整执行一次内层原生 I-V。内层卡输出按 Vg 分组的 Id-Vd；外层卡逐个漏压点回读并输出 HP 的 Ig-Vd，另可输出实际 Vg-Vd。

DP100 与光响应

节点用途
DP100 Laser I-V Calibration在 voltage ceiling、current min/max/step、settle、readback timeout、OVP/OCP 与 preset 下建立电流到电压表，只执行一次并输出 calibration data。
DP100 Laser Output设置 voltage/current limit/OVP/OCP、output state、preset、settle；Mapping 可选择 set once。
DP100 Waveform执行 software-timed 点列或 Pulse/Ramp/Staircase 程序；必须设置 final output state。
Power-gradient Pulse ResponseKeithley 固定 detector bias，同步 DP100 功率逐级升降，输出 I-t 与提取特征。
Pulse-width Gradient Response固定校准功率，递增 pulse width，记录响应。
Photo IV当前执行分支复用通用 IV sweep；dark_reference/light_settle/metric/bias 参数尚未被专用逻辑消费，声明的 photocurrent、dark ratio、responsivity 输出会成为 invalid/missing。不要把它用于自动暗亮扣除结论。
Photo Transient同步光脉冲列的 current-time；支持 bias hold、readback verify 与 rise/fall 提取。
Virtual Mask Illumination将灰度 image 的黑/白电功率按散点绑定映射到 XY 或 UV 坐标。
Mapping Heatmap把已连接数值特征发布成可选空间热图，本身不采集仪器数据。

计算、条件与显示

节点用途
Math Formula对标量/curve 执行受限表达式，定义变量、常量、输出类型/单位与 invalid 策略。
Add / Subtract / Multiply / Divide连接两个数值或使用 fallback constant；除法要处理零与 invalid。
Number Compare / Compare A/B数值与阈值或两个输入比较，输出 Boolean。
Boolean LogicAND/OR/XOR/NOT，支持缺输入 fallback。
Boolean Branch根据连接的 Boolean 选择控制路径。
Metric Condition读取上游 result metric path，与阈值比较。
Device State按粗 IV 的 resistance/current 阈值分类 open/short 等状态。
Compliance Check判断上游 sweep 是否触及 current/voltage compliance。
Plot Panel1×2 等布局，最多六个 slot；同源 curve family 可叠加，支持 linear/log scale 与手动轴/色标范围。

终止与证据

节点成功不仅依赖函数返回，还应产生预期 completion evidence：曲线终止、输出文件、readback 或 plot history。Stop、blocked 或 failed 后，运行器不会继续后续步骤。外部仪器输出状态必须在节点清理和现场仪器上双重确认。
