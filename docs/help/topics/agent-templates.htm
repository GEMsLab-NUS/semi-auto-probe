无设备命令行试用

uv run python -m semi_auto_probe.agent_demo --list
uv run python -m semi_auto_probe.agent_demo --all
uv run python -m semi_auto_probe.agent_demo --all --ready
uv run python -m semi_auto_probe.agent_demo --template focus_capture --ready
uv run python -m semi_auto_probe.agent_demo --preview --ready
uv run python -m semi_auto_probe.agent_demo --all --ready --output .runtime/agent-v2/templates-ready.jsonl

--ready 只构造虚拟就绪状态，不代表真实连接。演示始终使用本地规则；结果标为 SIMULATION，不建立硬件客户端或正式测量文件。--output 保存 UTF-8 JSONL。

Measurement 试用顺序

  1. 在 AutoTest → Config Measure Flow 载入一个符合当前设备的 Workflow v2 模板，并核对每个仪器限值。
  2. 配置 Probe 点表或 Wire-bond Mapping 区域。
  3. 发送 /check 并解决 blockers。通过只代表本地结构/geometry 通过。
  4. 发送 /run measurement，核对右侧 Steps 中的模式、点数、节点和 fingerprint，再 Run Next Step。
  5. 在原 AutoTest/Mapping 与 Plot Panel 检查真实结果和输出文件。

状态机回归

  • AutoFocus→capture 第一步运行中再次 Run Next Step：不得提前拍照。
  • 运行中 Cancel Plan：当前动作继续，后续取消；Stop 才请求停硬件。
  • 计划未运行前按 Stop：所有 pending 步骤取消。
  • 第一步运行中 Stop：等待原工作流清理，不自动继续第二步。
  • Conversation Only 加载任意硬件模板：只预览。
  • 生成 measurement 计划后修改 flow 或区域：旧计划必须 blocked。
  • 关闭 camera 后 capture：报告缺 frame；恢复后重新检查/规划。
