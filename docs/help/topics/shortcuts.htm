Main Position 与 Vision

  • 坐标数值单击：Relative；双击：Absolute；Enter 执行；Esc 清除；Tab/Shift+Tab 换轴。
  • Main microscope 中 Shift+click：把所选图像点移动到画面中心；需要像素/载台标定。
  • Polygon Area：按页面提示完成点选；双击或右击完成多边形。

SerialIO 与 AI Agent

两个输入框都用 Ctrl+Enter 发送。Agent 的发送仍遵循当前权限模式；SerialIO raw send 是维护接口，可能绕过高层互锁。

GDS / LayoutMap

  • 滚轮：zoom；左拖：pan；单击：选择目标。
  • 右拖：框选 zoom；右双击：Fit View。
  • Shift+左双击：触发到选中位置的真实 XY move。
  • 坐标输入 Enter：移动；Esc：清除。

ImgStitch 与 Mapping

  • ImgStitch mosaic：滚轮 zoom，左拖 pan，Shift+click move center。
  • Mapping canvas：Enter 提交 cell edit，Esc 取消，Backspace undo；滚轮 zoom，中/右拖 pan。

Measurement Flow Editor

  • Delete：删除选中节点；左拖 card；中键拖 canvas；右拖切断连线；滚轮缩放。
  • 各参数输入仍应使用 Validate；画布手势不会自动验证硬件限值。

DP100 Waveform Editor

  • Ctrl+Z / Ctrl+Y：Undo / Redo；A：auto-range；Delete：删除点。
  • 双击或 Ctrl+click：加点；Alt+click：删除点；拖点：编辑；背景拖动/滚轮：pan/zoom。
手势可真实运动。所有 move center、GDS move、键盘 jog 和滚轮 Z 在前置条件满足时会发送硬件动作。使用前确认当前焦点、Probe 状态、方向和 step。
