理解工作目录、自动恢复文件、各工作流 session 和完成证据。

共同规则。除显式选择路径外，默认相对路径都基于应用启动工作目录。复制实验数据时保留整个 session 目录，不要只复制截图或单个 CSV。

配置与可恢复上下文

路径内容
probe_config.local.json光学、相机、电机、AutoFocus、Agent 与 Wire-bond mode；可能含明文 API key。
last_autofocus_history.csv最近 AutoFocus 的运动、三种 score、采样、时间与终止帧。
last_focusmap_mapping.json自动保存/启动恢复使用的 FocusMap。
last_af_plane_mapping.jsonFocusMap 手动 Save Results 的默认名。
last_layoutbond_mapping.jsonGDS path/top cell、P1-P4、affine transform、FOV 与 residual。
workflow_library/<folder>/*.jsonMeasurement Workflow，format 为 semi_auto_probe.measurement_workflow、version 2。

ImgMatrix

imgmatrix_session/YYYYMMDD_HHMMSS[_NN]/
  manifest.json
  images/rNNN_cNNN_u..._v....png

manifest 记录版本、时间、设置、完成状态与每张图像坐标。每次 session 唯一，不覆盖同目录下旧运行。

AutoTest 与节点输出

autotest_session/YYYYMMDD_HHMMSS[_NN]/
  images/
  iv/
  wobb/
  hp6614c/
  b1500/
  workflow_plots/
  ... node execution JSON
  • Keithley IV 通常为 <device>_iv[_vtop_value][_N].csv 和同名 JSON。
  • WobbTest 为 <device>_wobb.csv/json。
  • HP 6614C 为 <device>_6614c_<test_type>.csv/json。
  • B1500 按 device 建子目录，可含 per-curve、ALL long/wide CSV、result JSON 与 Mapping 的 acquired_curves.jsonl。
  • Plot Panel 点历史位于 workflow_plots/<row>_<col>.json。

Wire-bond Mapping

autotest_session/YYYYMMDD_HHMMSS[_NN]/
  mapping.json
  samples.csv
  mapping.csv
  mapping.png
  mapping_artifacts.sqlite3
  points/...       (失败/中断时可能保留)

成功点的临时节点文件可压缩写入 SQLite 后删除 points/；失败/中断保留 loose tree。读取 Mapping 时同时检查 completed_points、点状态、SQLite/loose artifacts 与 workflow execution 信息。

Web 与本地运行日志

Web PID 和 tray logs 默认在 .runtime/。应用多数运行错误显示在当前页状态并写 Python logger；收集支持信息时记录启动命令、工作目录、配置副本（移除 secrets）、相关 session 与完整日志。

归档建议

  • 完成实验后把整个 timestamp session 复制到只读归档并计算 hash。
  • 记录软件 commit/version、config、GDS、FocusMap/LayoutMap、workflow JSON、仪器 resource 和样品 ID。
  • 不要把未完成 session 重命名成 completed；保留 Stop/failed 状态和 loose artifacts。
