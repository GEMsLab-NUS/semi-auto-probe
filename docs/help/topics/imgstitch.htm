ImgStitch

按当前区域采集 XY tile、T-stack 或 Z-stack，并重组成完整显微图像。

模式与区域

  • XY Stitch：按 rows/columns、spacing 或两个角点定义 tile 网格。
  • T-Stack：在同一位置按时间间隔连续采集。
  • Z-Stack：在指定 Z 数量、步长和方向上采集焦深序列。

XY 区域可使用 Array/Space 参数或 Two Points。先用当前 XY 记录角点，核对行列、step、overlap、扫描顺序和预估 tile 数，再开始运动。

Tile acquisition

每个 tile 可为 Single、T 或 Z 采集。T/Z 参数控制帧数、间隔、步长及合成方式。使用四角 AutoFocus 或 FocusMap plane 时，先保证对应数据有效；FocusMap 外推区域应单独验证。

Recompose

重组设置可控制 background correction、tile balance、crop、grid/质量叠加、估计位移和 Focus plane 使用。单击 Apply and Recalculate 只重新处理已有 tile，不重新采集；质量与位移视图用于检查接缝、重复纹理与失败 tile。

推荐操作

  1. 相机曝光、白平衡与照明稳定后，选择小区域并核对 overlap。
  2. 如果需要 Z 跟随，先加载或建立 FocusMap；若使用四角 AF，确保区域四角都能安全对焦。
  3. 启动采集并观察进度、Live Camera 和 mosaic。运动或图像异常时先按页面 Stop；顶栏急停当前不会设置 ImgStitch 循环的 stop event。
  4. 完成后检查接缝、亮度一致性、边界裁剪和实际覆盖范围，再 Save Full Image 导出 PNG/JPEG。

停止后的坐标

XY Stitch Stop 保留已采 tile/session，通常尝试回原 XYZ；Z-stack Stop 不执行原 Z 返回。任何停止后都应核对位置读回和探针间隙。

会话与文件覆盖

固定工作目录。每次建立新的 ImgStitch session 会重建启动目录下的 imgstitch_session/。需要保留的旧 tile、stack 或 session metadata 应在下一次新会话前复制或用 Save Full Image 导出。

常见文件包括 tiles/tile_rNNN_cNNN.png、session.json、recomposed_imgstitch.png、stack_result.png、raw_stack/ 和 last_imgstitch.png。AI Agent 的 single capture 使用独立、带时间戳的文件名，不再清空现有拼接会话。
