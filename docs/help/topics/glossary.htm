术语表

界面、坐标、扫描和测量中使用的名称。

术语含义
Stage X/Y/Z载台/探针机构的逻辑三轴坐标，桌面运动命令主要使用 controller pulse。
Layout U/VGDS 版图坐标，经 LayoutMap affine transform 与 Stage X/Y 互换。
pulse控制器离散位置单位；通过 microstep、丝杆导程等转换为物理距离。
Relative / Absolute相对于当前位置的增量 / 控制器坐标中的目标值。
zero / Go Zero控制器坐标 0；Go Zero 是移动到 0，不是寻限位。
Home / Go Home控制器 homing 流程，具体物理含义依现场机构与协议。
Separate / Contact探针被视作离开样品 / 接触样品的状态。
Safe Z用于横向移动或恢复的抬起高度/余量；不能自动保证越过所有夹具。
FOVField of View，相机在样品/版图上的视场宽高与旋转。
Focus scoreLaplacian、Tenengrad 或 Brenner 计算的图像清晰度指标。
FocusMap多个 XY 点的最佳 Z 与拟合 sample plane model。
LayoutMap / LayoutBond当前可见名 / 内部历史名；将 GDS U/V 映射到 Stage X/Y。
tileImgStitch 网格中的单个视场图像。
T-stack / Z-stack同位置的时间序列 / 沿 Z 的图像序列。
serpentine / raster交替行方向扫描 / 每行同方向并回绕。
Workflow v2由类型化 control/data edge 连接的 Measurement Workflow JSON format version 2。
control edge / data edge规定执行顺序的连线 / 传递 scalar、Boolean、curve 或 calibration 的连线。
compliance仪器为保护器件而施加的电压或电流限制。
NPLC按电网周期计的积分时间；通常越大越慢、噪声越低。
VISA resource如 GPIB0::18::INSTR 的仪器连接标识。
MappingWire-bond 模式下，在区域网格按固定 Z 执行每点 workflow 并汇总空间结果。
manifest / execution evidence记录任务设置、点/节点状态、文件与完成事实的结构化数据。
fingerprintAgent 计划生成时对 workflow 与扫描 geometry 的签名；配置变化会使旧计划失效。
blocker因状态、前置条件或参数不满足而阻止 Agent/工作流执行的原因。
CHM / context IDWindows Compiled HTML Help 文件 / F1 用于定位具体主题的稳定数字标识。
