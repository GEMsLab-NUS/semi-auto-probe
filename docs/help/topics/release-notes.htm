本版同步内容

  • 页面名称以 MainView、LayoutMap、SerialIO、Settings 等当前可见标签为准，并兼容旧内部名。
  • AutoTest 文档以类型化 Measurement Workflow v2 为准，删除旧的顺序 cards 说明。
  • 补入 Wire-bond Rectangle/Circle/Polygon、Mapping SQLite、HP 6614C、2450 Fixed-bias、DP100、TEMT6000、公式/条件和 Plot Panel。
  • AI Agent 采用 Conversation Only、Authorized Step、Auto Step，记录 blocker、fingerprint 和 completion evidence；旧 Ask only/Admin full access 说明不再适用。
  • Web 明确为 session 数据浏览器；不提供 camera、motion 或 E-stop。只有设置 WEB_TOKEN 后才启用认证。
  • 所有界面截图由当前应用在离线文档模式重新生成。

当前功能边界

  • IT、Light Control、Light Pulse、Switch Wavelength 仍是占位节点，Workflow v2 预检拒绝执行。
  • Photo IV 当前复用通用 IV 执行，尚未生成声明的 dark/photocurrent/responsivity 特征。
  • WobbTest 当前返回 best current，尚未生成声明的 contact resistance。
  • ImgMatrix、EdgeTrace、连接与任意仪器配置由 AI Agent 提供帮助/导航，不由 Agent 直接操作。
  • CHM 使用传统 Windows HTML Help viewer；页面采用无 JavaScript 的保守 HTML/CSS，视频不编入。
  • 当前顶栏急停不设置 ImgStitch/EdgeTrace stop event；EdgeTrace Stop 不自动抬到 safe Z；Probe Test Stop/正常结束也不统一抬针。单轴 Stop 后的位置刷新有已知错误。这些硬件语义在安全章节明确记录。

维护规则

发布功能、UI label、节点端口、输出路径或安全语义改变时，应同步更新 topics、TOC、index、context map 与截图，运行 source verifier，编译 CHM，并用 hh.exe -decompile 检查容器。已发布 context ID 只新增、不重排。
