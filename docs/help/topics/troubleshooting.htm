SEMI AUTO PROBE · OFFICIAL HELP

故障排查

按状态、前置条件、连接和完成证据定位问题。

应用启动或配置异常

现象处理
设置像恢复默认确认启动工作目录及其中的 probe_config.local.json。无效 JSON 会回退默认并只写 logger；用 JSON parser 检查格式，保留损坏副本。
页面过窄或控件不可见主窗最小 1040×600；最大化或使用页面滚动栏。不要依赖旧 manual-deck 截图。
F1 无法打开确认安装目录的 SemiAutoProbeHelp.chm 存在；可用 SEMI_AUTO_PROBE_HELP_FILE 指向本地 CHM。若从浏览器下载，文件属性中解除阻止；避免从 UNC/network 直接打开。

Serial / motion

  • 没有 COM：设备管理器、驱动、线缆，再 Refresh。
  • 连接失败：端口占用、电源/RS-232、Local/Remote 模式；默认协议 115200 8-N-1。
  • Test 失败：查看 SerialIO 的完整 LAST TX/RX 和 history；默认响应前缀应为 A3 AA。
  • Motion busy / locked：等待当前 workflow 或用对应 Stop；检查位置读回任务、FocusMap/AF/ImgStitch 占用。
  • 方向错误：停止，保持 Separate；在 Settings 核对 motor mapping 与 axis direction，以最小 jog step 重试。
  • FocusMap Z 锁住 Z：关闭 MainView 的 FocusMap Z，或使用随平面的 XY 目标。

Camera / image

  • 换用 auto、miicam:0 或正确 OpenCV/ToupCam source；关闭占用相机的软件并按 Restart。
  • 自定义 MiiCam SDK 路径用 SEMI_AUTO_PROBE_MIICAM_SDK；检查 DLL 架构与驱动。
  • Vision move disabled 通常表示缺当前倍率/分辨率的 pixel calibration 或 stage conversion。
  • 曝光饱和、噪声或自动白平衡漂移会破坏 focus score 与拼接；先固定照明和相机参数。

AutoFocus / FocusMap

  • No camera frame：相机未产生 frame；先在 MainView 验证。
  • 峰值在边界：搜索范围不足、初始 Z 偏离、步长过大或方向错误；停止并重新设范围。
  • 阈值 invalid：Settings 的 green 必须 ≥ yellow。
  • 平面 fit pending：需要至少 3 个有效非共线点；检查 failed/retry 与残差。
  • 导入后不匹配：确认样品、零点、光学倍率和 mesh 坐标未改变。

LayoutMap / imaging

  • GDS 载入失败时确认 gdstk 已安装、文件有效、top cell/layer 存在。
  • Mapping residual 高时重新选择分布良好的 P1-P3/P4；不要用近共线点。
  • 拼接接缝差时检查 overlap、stage step、曝光、flat/background correction、纹理重复、FocusMap 和 settle。
  • ImgMatrix 路径错位时检查 U/V basis、FOV rotation 和 stage↔GDS mapping。

Workflow / instruments

  • Validate 先处理断开的 control/data edge、类型、START/END、条件分支和非法参数。
  • IT、Light Control、Light Pulse、Switch Wavelength 是占位节点，正式预检会拒绝。
  • VISA 失败时核对 resource、前/后 terminal、驱动、仪器锁和连接；本地 /check 不会测试连通性。
  • 触及 compliance、Stop 或异常后，现场确认 Keithley/HP/B1500/DP100 输出已关闭。
  • Photo IV 当前执行为通用 IV，未产生其声明的 dark/photocurrent/responsivity 特征；WobbTest 当前不产出 contact_resistance_ohm。下游应检查 invalid/missing。

AI Agent

  • API off：无 key 仍可使用本地 help/status/check/open/run routing，不是故障。
  • Provider failed：查看错误原因；系统会退到本地规则。
  • Planning already running / empty input：等待当前请求或输入有效指令。
  • Blocked：逐条解决 Probe Contact、serial/camera、motion busy、mesh/mapping/target 或 measurement fingerprint blocker，再重新规划。
  • Cancel Plan 不停止已经运行的动作；使用 Stop。

Web / data

  • 401：核对服务进程中的 WEB_TOKEN 与浏览器 localStorage/header。
  • 没有 session：核对 SEMI_AUTO_PROBE_AUTOTEST_SESSION_DIR 和服务启动工作目录。
  • 只有部分文件：检查任务 status、completed points、manifest、execution JSON、SQLite 和 loose points/，不要只看 PNG。

仍无法解决：保存启动命令、版本/commit、脱敏 config、相关 session、日志、Serial TX/RX 与复现步骤。
