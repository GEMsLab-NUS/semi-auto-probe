SEMI AUTO PROBE · OFFICIAL HELP

快速开始

从安装到第一次安全移动、对焦和保存结果。

开始前：确认机械行程内没有障碍物、探针处于 Separate、样品和夹具固定、控制器及仪器输出处于安全状态。首次使用先阅读 安全、探针与急停。

1. 安装与启动

  1. 在项目根目录安装依赖：uv sync。使用 DP100 时还需安装可选依赖：uv sync --extra dp100。
  2. 从期望作为工作目录的文件夹启动：uv run semi-auto-probe。配置文件和默认输出目录都以启动工作目录为基准。
  3. 需要恢复上次 FocusMap 与 LayoutMap 时使用 uv run semi-auto-probe --restore-last。

2. 建立桌面连接

  1. 在顶栏 SERIAL 选择 Local 或 Remote，选择端口后单击 Connect。状态区应显示连接成功。
  2. 单击 Test 做协议测试。默认期望接收帧以 A3 AA 开头；失败时转到 SerialIO 查看 TX/RX。
  3. 在 CAM 选择相机源并单击 Restart。MainView 应出现实时图像。相机源可为 auto、miicam:0 或 OpenCV/ToupCam 形式。

3. 核对 Settings

  1. 选择实际的 objective 和 eyepiece；用已知尺寸标尺执行 Calibrate Pixels。
  2. 核对电机轴映射、方向、microstep、丝杆导程与速度配置。若使用控制器 D5 参数，先 Read D5 X/Y/Z 再决定临时 Apply 或掉电保存。
  3. 设置适合样品的 safe Z margin、AutoFocus settling/sample count、Focus score 阈值，然后 Save Config。
  4. 只有经过授权的维护人员才应启用 Admin；Set New Zero、Go Home 和 Wire-bond 模式开关受 Admin 保护。

4. 第一次移动与对焦

  1. 打开 MainView，保持 Probe 为 Separate。
  2. 选择较小 jog step 和 Safe/Fine 速度，单击 X/Y/Z 的 Fwd/Rev。每次动作后核对位置读回。
  3. 切换到 AutoFocus，用小范围手动 Z 动作确认正负方向，再运行一次自动对焦。
  4. 需要区域对焦时，在 FocusMap 生成小网格并先用 Dry run 验证路径。

5. 第一次自动化任务

图像任务从 ImgMatrix 或 ImgStitch 开始；电学/光学测量从 AutoTest 配置点位，再在 Measurement Workflow v2 中连接节点。首次运行应减少点数、关闭高风险输出并使用保守限值。

输出位置。配置保存在 probe_config.local.json；ImgMatrix、ImgStitch、AutoTest 和 Mapping 会在启动工作目录下建立各自会话目录。完整清单见 文件、会话与导出。
