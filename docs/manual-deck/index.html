AutoFocus

Z scan, focus score, and best focus return

The optical stack stays fixed. The stage scans Z, scores image sharpness, fits the focus curve, then returns to the best Z.

Laplacian metric selected · coarse scan then local refinement
Focus Mapping

Fit the sample plane, then let Z follow XY

Focus Mapping solves large-area defocus by sampling multiple points, running AutoFocus at each location, fitting a plane, and enabling automatic Z compensation.

Point inspector

Image Stitching

Build a large field from local high-resolution images

Use stitching to scan a local grid, register overlapping fields, and compose a larger microscope image with visible quality feedback.

XY Stitching · serpentine scan · overlap 20% · weight 0.65

Configuration

Stable defaults, adjustable hardware profiles

The configuration page stores relatively fixed parameters: optical magnification, input mode, fitting defaults, motion speed, acceleration, and stability settings. Most daily workflows should work with default settings.
